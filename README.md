# S&P 500 Algorithmic Trading System

Python-based algorithmic trading research project
deployed on Google Cloud Platform.

## Technology
- Python
- Google Cloud Run
- Cloud Scheduler
- Cloud Storage
- pandas
- yfinance

## Current features
- Historical SPY price data collection
- SMA20/SMA50 trading signals
- Automated daily execution
- Cloud-based signal storage

## Roadmap
- Historical backtesting
- Performance metrics
- Paper trading
- Buy-and-hold comparison

## Disclaimer
Educational research project.
No real-money trading.
